# Experiment 002 — Investigation vs Routine Throughput

Status: **measured inside Anomaly Garden v0.7.0**

This note describes a property of the simulation, not a claim about humans, work, economics, organizations, or society.

Using the same 24-seed repair-policy batch at tick 80:

| Metric | Repair off | Tolerant | Aggressive |
| --- | ---: | ---: | ---: |
| investigations | 13.46 | 6.21 | 0.17 |
| model breaks | 13.38 | 5.58 | 0.04 |
| workplace production | 11.34 | 13.81 | 16.66 |
| social meetings | 3.33 | 6.33 | 12.08 |
| projects completed | 0.33 | 1.13 | 1.13 |
| institution sessions | 14.75 | 22.13 | 22.38 |

Investigation can override ordinary routine, while accepted institution commitments can redirect only phase-appropriate time: inquiry uses social/home time, maintenance uses work time, and commons proposals use social time. Therefore part of the throughput direction is explicitly designed into the mechanics. Exact magnitudes remain seed- and interaction-dependent.

The purpose of this table is regression, not a social conclusion.
